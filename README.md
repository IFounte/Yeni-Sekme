# Özel Yeni Sekme (New Tab) - Tek Dosya (All-in-One)

Bu proje, Chromium tabanlı tarayıcılarda (Google Chrome, Microsoft Edge, Brave, Opera vb.) kullanılabilen modern, kişiselleştirilebilir ve **tamamen tek bir HTML dosyası içine sığdırılmış** bir yeni sekme sayfasıdır.

---

## 🌟 Dosya Yapısı

Tüm HTML yapısı, CSS stilleri (Glassmorphism, animasyonlar) ve JavaScript kodları (IndexedDB arka plan yönetimi, saat, Türkçe tarih, Google arama, hızlı erişim kısayolları) **[newtab.html](file:///c:/Users/Founte/Documents/Karışık/Yeni%20Sekme%20Projesi/newtab.html)** dosyasının içindedir. Ekstra hiçbir `css` veya `js` klasörüne ihtiyaç duymaz.

---

## 🚀 Nasıl Kullanılır?

### 1. Doğrudan Tarayıcıda Açma / Başlangıç Sayfası Olarak Ayarlama:
- [newtab.html](file:///c:/Users/Founte/Documents/Karışık/Yeni%20Sekme%20Projesi/newtab.html) dosyasına çift tıklayarak istediğiniz tarayıcıda hemen açabilirsiniz.
- Tarayıcınızın Ayarlar -> "Başlangıçta" / "Ana Sayfa" bölümüne bu dosyanın tam yolunu yapıştırarak her açılışta gelmesini sağlayabilirsiniz.

### 2. Chrome / Edge Uzantısı Olarak Yükleme:
1. Tarayıcınızda `chrome://extensions` adresine gidin.
2. Sağ üstten **Geliştirici modu**nu açın.
3. **Paketlenmemiş öğe yükle** butonuna basarak bu klasörü seçin.
4. Yeni bir sekme (`Ctrl + T`) açın.
